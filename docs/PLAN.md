# 시스템 프로그래밍 학습용 투명 쉘 - 프로젝트 계획서

## 1. 개요

| 항목 | 내용 |
|---|---|
| 과목 | 오픈소스프로젝트(전공설계) |
| 주제 | 시스템 프로그래밍 학습용 투명 쉘 |
| 팀명 | myshell |
| 팀원 | 류동엽(20223154), 강동우(20223080) |
| 저장소 | https://github.com/gong000000/lab3 |

## 2. 목표

- Lab 3의 5개 요구사항과 11개 내장 명령을 구현한다.
- 명령 실행뿐 아니라 파서, 파이프, 시스템 호출, ELF, `/proc` 상태를 확인하는 도구를 제공한다.
- 세션을 기록·재생하고 결과를 HTML로 남길 수 있게 한다.
- 자동 테스트로 기능과 회귀를 검증한다.

## 3. 설계 구성 요소

| 구성 요소 | 수행 내용 |
|---|---|
| 목표/기준 설정 | 5개 요구사항, 11개 내장 명령, 관찰 도구 6종 |
| 합성 | libc/POSIX 시스템 콜을 조합해 쉘과 도구 구성 |
| 분석 | simplesh.c, 파서/실행기, 프로세스/시그널, ptrace/ELF/proc |
| 제작 | main, parser, execute, jobs, builtin, cmd_* 모듈 |
| 시험 | 기능·확장·추적·디버거·녹화·조사·PTY 테스트 |
| 평가 | 완성도, 일정, 역할, 위험 처리 |
| 결과 도출 | README, LICENSE, 결과보고서, 테스트 스크립트 |

## 7. 위험 관리

| 위험 | 대응 |
|---|---|
| 전경 작업 시그널 | setpgid, tcsetpgrp, 자식 신호 기본값 복원 |
| 좀비 프로세스 | waitpid(WNOHANG) 주기 회수 |
| 파일 디스크립터 누수 | dup2 후 close, 재지향 실패 시 복원 |
| PIE 주소 불일치 | /proc/PID/maps에서 로드 기준 주소 계산 |
| ptrace 차단 | PTRACE_TRACEME로 자기 자식만 추적 |
| 녹화 출력 | 전경 relay, 백그라운드 지연 캡처 |
